Integración Directa

Fórmulas básicas de integración

La integración directa consiste en reconocer que una función es la derivada de otra ya conocida, y "deshacer" esa derivada. Estas son las reglas básicas (todas se pueden comprobar derivando el lado derecho):

$$\int x^n\,dx = \frac{x^{n+1}}{n+1}+C \ \ (n\ne -1) \qquad\qquad \int \frac{1}{x}\,dx = \ln|x|+C$$ $$\int e^x\,dx = e^x+C \qquad\qquad \int \cos x\,dx = \sin x+C \qquad\qquad \int \sin x\,dx = -\cos x+C$$ $$\int k\,dx = kx+C \qquad\qquad \int \big[a\,f(x)+b\,g(x)\big]dx = a\!\int\! f(x)\,dx + b\!\int\! g(x)\,dx$$

La última fórmula (linealidad) es la que permite integrar término por término: se integra cada parte de una suma por separado.

Ejemplos resueltos

Ejemplo 1 — Regla de la potencia (término a término)

Calcular $\displaystyle\int (4x^3-2x+7)\,dx$.

Paso 1 — Separar por linealidad $$\int 4x^3\,dx - \int 2x\,dx + \int 7\,dx$$
Paso 2 — Aplicar la regla de la potencia a cada término $$4\cdot\frac{x^4}{4} - 2\cdot\frac{x^2}{2} + 7x$$
Paso 3 — Simplificar $$\int (4x^3-2x+7)\,dx = x^4-x^2+7x+C$$

Comprobación: la derivada de $x^4-x^2+7x$ es $4x^3-2x+7$. ✓

Ejemplo 2 — Función exponencial

Calcular $\displaystyle\int (e^x+3)\,dx$.

Paso 1 — Separar por linealidad $$\int e^x\,dx + \int 3\,dx$$
Paso 2 — Aplicar las fórmulas directas $$\int (e^x+3)\,dx = e^x+3x+C$$

Ejemplo 3 — Funciones trigonométricas

Calcular $\displaystyle\int (2\cos x - \sin x)\,dx$.

Paso 1 — Separar por linealidad $$2\int \cos x\,dx - \int \sin x\,dx$$
Paso 2 — Aplicar las fórmulas directas $$2(\sin x) - (-\cos x)$$
Paso 3 — Simplificar $$\int (2\cos x - \sin x)\,dx = 2\sin x+\cos x+C$$

Comprobación: la derivada de $2\sin x+\cos x$ es $2\cos x-\sin x$. ✓

Ejemplo 4 — Función racional 1/x

Calcular $\displaystyle\int \frac{5}{x}\,dx$ para $x>0$.

Paso 1 — Sacar la constante $$5\int \frac{1}{x}\,dx$$
Paso 2 — Aplicar la fórmula directa $$\int \frac{5}{x}\,dx = 5\ln|x|+C$$
